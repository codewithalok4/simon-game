# 🎮 Simon Game

A simple **Simon Game** built using **HTML, CSS, and JavaScript**.
The game generates a sequence of colors that the player needs to remember and repeat correctly. The sequence gets longer as the player progresses through each level.

## 🚀 Features

* 🎨 Random color sequence generation
* ⌨️ Start the game by pressing any key
* 🖱️ User interaction through button clicks
* 📈 Increasing difficulty with each level
* ✨ Button flash animations
* ❌ Game-over detection when the wrong color is selected
* 🔄 Game reset functionality

## 🎯 How to Play

1. Press **any key** to start the game.
2. Watch the color that flashes.
3. Click the color that was generated.
4. In the next level, remember the previous sequence and click the colors in the correct order.
5. Continue until you select the wrong color.
